# 물결안심 웹사이트

동네 소하천 산책로 이용자가 주변 위험 상태를 확인하고 안전 행동을 판단하도록 돕는 반응형 웹사이트 시안입니다.

## 화면 구성

- **실시간 현황**: 3단계 위험 상태, 수위 게이지, 현장 계측 예시, 진입로 상태
- **내 주변**: 하천·지역 검색, 모니터링 구간 목록, 지도 형태의 위치 시안
- **하천 상세**: 수위 및 센서 카드, 진입로별 상태
- **알림 내역**: 위험 안내 목록, 상태 필터, 읽음 처리
- **안전 행동 요령**: 통제 시 행동 단계와 119 연락 링크
- **설정 및 안내**: 위치 권한 안내, 데이터 연결 상태와 서비스 범위
- **예외 화면**: 위치 확인 실패, 대상 하천 없음, 데이터 호출 오류 시안

## 실행

`index.html`을 최신 브라우저에서 열면 됩니다. 빌드 도구나 외부 라이브러리는 필요하지 않습니다.

## 데이터 범위

화면 속 수위·강수량·위험 단계·하천·알림은 모두 시안용 예시입니다. 기상청·지자체 API, CCTV, 실제 GPS, 백그라운드 위치 추적, 푸시 알림은 연결되어 있지 않습니다. 실제 서비스 전에는 데이터 제공 범위와 갱신 주기, 하천별 위험 임계값, 알림 동작을 확정해야 합니다.

위험 단계 시안과 예외 화면은 화면 하단 또는 설정 화면의 **화면 시안 상태 바꾸기 / 예외 화면 시안**에서 확인할 수 있습니다.
