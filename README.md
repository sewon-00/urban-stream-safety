# 물결안심 웹사이트

동네 소하천 산책로 이용자가 주변 위험 상태를 확인하고 안전 행동을 판단하도록 돕는 반응형 웹사이트 시안입니다.

## 화면 구성

- 실시간 위험 현황과 수위 기준 안내
- 주변 하천 검색과 모니터링 구간 목록
- 하천 상세 계측 정보와 진입로별 상태
- 알림 내역, 필터, 읽음 처리
- 통제 시 안전 행동 요령과 119 연락 링크
- 위치 권한·데이터 연결 안내 및 예외 화면

## 실행

`index.html` 하나로 구성되어 있습니다. 최신 브라우저에서 파일을 열면 되며 빌드 도구나 별도 라이브러리가 필요하지 않습니다.

## 데이터 범위

화면 속 수위·강수량·위험 단계·하천·알림은 모두 시안용 예시입니다. 기상청·지자체 API, CCTV, 실제 GPS, 백그라운드 위치 추적, 푸시 알림은 연결되어 있지 않습니다. 실제 서비스 전에는 데이터 제공 범위와 갱신 주기, 하천별 위험 임계값, 알림 동작을 확정해야 합니다.
